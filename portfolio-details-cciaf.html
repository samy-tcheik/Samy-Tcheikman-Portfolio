CCIAF Events - Event Manager App

Project information

  • Category: Mobile App (Android & iOS)
  • Client: CCIAF
  • Project date: 2024
  • Tech Stack: React Native, Laravel API, Push Notifications
  • Project URL: Coming soon

Event manager mobile app developed for client CCIAF. It centralizes events, programs, speakers and registrations in one modern mobile experience, with QR check-in for organizers.

  • Events feed with program & speakers
  • Online registration & ticketing
  • QR code check-in for organizers
  • Push notifications for updates
  • Admin dashboard via Laravel API
