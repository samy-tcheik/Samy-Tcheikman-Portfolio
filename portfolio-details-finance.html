Finance Manager - Personal Finance App

Project information

  • Category: Mobile App (Android & iOS)
  • Client: Personal Project
  • Project date: 2024
  • Tech Stack: React Native, SQLite / Offline-first, Charts
  • Project URL: Coming soon

Finance Manager is a personal finance management app to track expenses and income, set budgets and visualize spending with clean charts. Offline-first for speed and privacy.

  • Expenses & income tracking with categories
  • Monthly budgets & alerts
  • Charts & statistics dashboard
  • Offline-first with local storage
  • Export & recurring transactions
